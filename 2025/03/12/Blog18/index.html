摘要：本文梳理上午考试操作系统知识的后半部分，包括分区、页式、段式、段页式存储管理，页面置换算法与快表，文件管理与空闲空间管理，设备管理与 SPOOLING 技术，以及微内核和嵌入式操作系统。

一、存储管理基础

存储器的结构层次为：寄存器 → 高速缓存 Cache → 主存 → 外存。

地址重定位是把逻辑地址转换为实际主存物理地址的过程，分为静态重定位（程序装入主存时完成转换）和动态重定位（边运行边转换）。

分区存储管理

分区存储就是把进程运行所需的内存整体分配给它再执行，有三种方式：

  • 固定分区：把主存分成若干固定分区，由于分区大小和作业需求大小不同，会产生内部碎片
  • 可变分区：在作业转入时按需划分，不存在内部碎片，但容易把主存切割成许多小块，产生外部碎片
  • 可重定位分区：移动已分配区域使其连续，从而把零碎分区合并成大的分区，只在外部作业请求空间得不到满足时进行

可变分区的内存分配算法（设需要分配 9K）：

算法 做法
首次适应法 按地址顺序从头查找，找到第一个 ≥9K 的空闲块切割分配
最佳适应法 把空闲块按从小到大排序，找到第一个 ≥9K 的块，即与需求最接近的块
最差适应法 选择最大的空闲块切割分配，以预防产生过多细小空闲块
循环首次适应法 接着上次查找的位置继续找，不必每次从头查找

二、页式存储管理

页式存储基于可变分区提出，把进程空间分成一个个大小相同的页，把物理内存分成同样大小的物理块，需要运行的逻辑页装入物理块即可运行，解决了进程所需内存大于系统内存的问题。

逻辑地址由「页号 + 页内地址」组成，页内地址就是物理偏移地址；页号与物理块号不是按序对应的，需要查询页表才能得知对应关系，最终物理地址 = 物理块号 + 页内偏移地址。

优点是利用率高、碎片小、分配及管理简单；缺点是增加了系统开销，可能产生抖动现象。

页面置换算法

当进程页面数多于系统物理块数时，需要按算法淘汰部分页面，缺页表示要执行的页不在内存中，需要从外存调入，会增加执行时间，因此缺页越多系统效率越低。

  • 最优算法 OPT：理论算法，无法实现，用于给其他算法提供效率比较基准，原理是置换未来最长时间内不被访问的页面
  • 先进先出 FIFO：先调入内存的页先被淘汰，可能产生抖动现象，即分配的页数越多缺页率反而越高
  • 最近最少使用 LRU：淘汰最近过去最少使用的页面，根据局部性原理效率较高且不产生抖动，需要大量计数器但比 LFU 少

淘汰原则：优先淘汰最近未访问的页面，其次淘汰最近未被修改的页面。

快表

快表是一块小容量的相联存储器，按内容访问，能从硬件上保证按内容并行查找，用来存放当前访问最频繁的少数活动页面的页号。

快表是把页表存在 Cache 中，慢表是把页表存在内存中。慢表需要访问两次内存才能取出页，快表只需访问一次 Cache 和一次内存，因此更快。

三、段式存储管理

段式存储把进程空间分成一个个段，每段有段号和段内地址。与页式不同，分段是按逻辑整体划分的，每段物理大小不同。

段表有段长和基址两个属性，用以确定逻辑段在物理内存中的位置；段内偏移不能超过该段号对应的段长，否则产生越界错误。真正内存地址 = 段号对应的基址 + 段内偏移。

优点是便于多道程序共享内存，各段程序修改互不影响；缺点是内存利用率低，内存碎片浪费大。

页式与段式的区别：分页是根据物理空间划分，每页大小相同；分段是根据逻辑空间划分，每段是一个完整的功能，便于共享，但大小不同。

四、段页式存储管理

段页式是先分段、后分页，兼有两者的特点。优点是空间浪费小、存储共享容易、存储保护容易、能动态链接；缺点是管理软件增加导致复杂性和开销增加，需要更多硬件和内存储器，执行速度明显下降。

五、文件管理

索引文件结构

以 13 个索引节点为例：0～9 号是直接索引，每个索引节点直接存放内容，假设每个物理盘块 4KB，共可存 4KB × 10 = 40KB 数据。

10 号是一级间接索引节点，存放的是物理盘块的地址，若每个地址占 4B，则共有 1024 个地址，可存 1024 × 4KB 数据；11 号是二级间接索引，容量再扩大一个数量级；12 号是三级间接索引。

目录结构与路径

文件安全分为四级，从高到低为：系统安全、用户安全、目录安全、文件安全。

  • 相对路径：从当前路径开始的路径
  • 绝对路径：从根目录开始的路径
  • 全文件名 = 绝对路径 + 文件名（绝对路径和相对路径本身不含最后的文件名）

文件属性包括：R 只读文件、A 存档属性、S 系统文件、H 隐藏文件。文件名由驱动器号、路径、主文件名、扩展名组成。

空闲存储空间管理

方法 说明
空闲区表法 把所有空闲空间整合成一张表，即空闲文件目录
空闲链表法 把所有空闲空间链接成一个链表，按需分配
成组链接法 分组的同时组内链接成链表，是前两种方法的综合
位示图法 对每个物理空间用一位标识，1 表示已使用，0 表示空闲，形成一张位示图

六、设备管理

设备的分类：按数据组织分为块设备、字符设备；按资源分配角度分为独占设备、共享设备、虚拟设备；按传输速率分为低速、中速、高速设备。

I/O 软件分为四层：用户进程层（进行 I/O 调用、格式化 I/O、SPOOLing）、设备无关软件层（命名、保护、阻塞、缓冲、分配）、设备驱动程序层（设置设备寄存器、检查状态）、中断处理程序层（I/O 结束时唤醒驱动程序），最下面是硬件层。

输入输出技术

方式 特点
程序控制（查询）方式 CPU 主动查询外设是否完成传输，效率极低
程序中断方式 外设完成传输后向 CPU 发中断，效率相对较高，适用于键盘等实时性要求高的场景
DMA 方式 CPU 只需完成初始化，数据传输全程由 DMA 控制器完成，在主存和外设之间建立直接数据通路，适用于硬盘等高速设备
通道方式 通道本身也是一种处理机，具有独立处理系统，使数据传输独立于 CPU，分为字节多路通道和选择通道

中断相关概念：中断响应时间是从发出中断请求到开始进入中断处理程序；中断处理时间是从进入中断处理开始到结束；中断向量提供中断服务程序的入口地址；多级中断嵌套用堆栈保护断点和现场。

注意响应时机的区别：CPU 响应 DMA 请求是在一个总线周期结束后，而响应程序中断请求是在一条指令执行结束时。

虚设备与 SPOOLING 技术

一台物理设备（如打印机）同一时间只能由一个进程使用，其他进程只能等待，浪费了外设效率。

SPOOLING 技术在外设上建立输入井和输出井两个数据缓冲区，各进程把打印命令发出后数据排队存入缓冲区，打印机按顺序自动打印，实现了物理设备的共享，使每个进程都感觉自己独占打印机，这就是物理设备的虚拟化。

七、微内核与嵌入式操作系统

对比项 单体内核 微内核
实质 图形、设备驱动及文件系统等功能全部在内核中实现，运行在内核态和同一地址空间 内核只实现基本功能，图形系统、文件系统、设备驱动及通信功能放在内核之外
优点 减少进程间通信和状态切换开销，运行效率高 内核精练，便于剪裁和移植；系统服务运行在用户地址空间，可靠性和安全性较高；可用于分布式系统
缺点 内核庞大，占用资源多且不易剪裁，稳定性和安全性不好 用户态与核心态需要频繁切换，系统效率不如单体内核

嵌入式操作系统的特点：微型化、代码质量高、专业化、实时性强、可裁剪可配置。

实时嵌入式操作系统的内核服务包括异常和中断、计时器、I/O 管理。常见的嵌入式 RTOS 有 VxWorks、RT-Linux、QNX、pSOS。其中 VxWorks 的操作系统与应用程序处于同一存储空间，任务间无隔离保护；RT-Linux 两者处于不同存储空间，支持进程间隔离保护，安全性更好。
