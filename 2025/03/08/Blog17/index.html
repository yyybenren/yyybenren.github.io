摘要：本文梳理上午考试操作系统知识中的进程管理部分，包括操作系统概述、进程的状态与组成、前趋图与进程资源图、同步与互斥、信号量 PV 操作、进程调度算法和死锁的四个必要条件与处理方法。

一、操作系统概述

操作系统的作用：通过资源管理提高计算机系统的效率；改善人机界面，向用户提供友好的工作环境。

操作系统有四个特征：并发性、共享性、虚拟性、不确定性。

操作系统的功能包括：进程管理、存储管理、文件管理、设备管理、作业管理。

操作系统的分类：批处理操作系统、分时操作系统（轮流使用 CPU 时间片）、实时操作系统（快速响应）、网络操作系统、分布式操作系统（物理分散的计算机互联系统）、微机操作系统、嵌入式操作系统。

嵌入式系统的初始化过程按照自底向上、从硬件到软件的次序为：片级初始化 → 板级初始化 → 系统初始化。芯片级是微处理器的初始化，板卡级是其他硬件设备的初始化，系统级是软件及操作系统的初始化。计算机启动的基本流程为：BIOS → 主引导记录 → 操作系统。

二、进程的状态与组成

进程由三部分组成：进程控制块 PCB（唯一标志）、程序（描述进程要做什么）、数据（进程执行时所需的数据）。

进程的三态图是系统自动控制时的三种基本状态：运行、就绪、阻塞。五态图在三态基础上增加了静止就绪和静止阻塞，需要人为操作才能进入，活跃就绪即就绪，活跃阻塞即等待。

  • 运行 → 就绪：时间片到
  • 就绪 → 运行：被调度
  • 运行 → 阻塞：等待某个事件
  • 阻塞 → 就绪：等待的事件发生
  • 人为挂起后进入静止状态，需要人为激活才能恢复到活跃状态，其本质仍是三态转换

三、前趋图与进程资源图

前趋图用来表示哪些任务可以并行执行、哪些任务之间有顺序关系。

进程资源图用来表示进程与资源之间的分配和请求关系：P 代表进程，R 代表资源，R 方框中有几个圆球就表示有几个该类资源。R 指向 P 表示资源已分配给该进程，P 指向 R 表示该进程还需要请求该资源。

  • 阻塞节点：进程所请求的资源已经全部分配完毕，无法继续执行
  • 非阻塞节点：进程所请求的资源还有剩余，可以继续运行

当一个进程资源图中所有进程都是阻塞节点时，系统陷入死锁状态。

进程资源图的化简方法：先看系统还剩多少未分配资源，找出不阻塞的进程，去掉它的所有边使其成为孤立点，再回收分配给它的资源；重复以上过程，直到所有资源和进程都变成孤立点。若无法化简到全部孤立，说明存在死锁。

四、同步与互斥

互斥和同步不是反义词。

  • 互斥：一个资源在同一时间内只能由一个任务单独使用，需要加锁，用完解锁后其他任务才能使用
  • 同步：两个任务可以同时执行，只是有速度差异，需要速度上匹配，不涉及资源是否单独使用的问题

信号量与 PV 操作

  • 临界资源：需要用互斥方式共享的资源，某一时刻只能被一个进程使用
  • 临界区：进程中访问临界资源的那段代码
  • 信号量：一种特殊的变量

信号量分为两类：互斥信号量用于对临界资源的互斥访问，初值为 1；同步信号量用于对共享资源的访问控制，初值是共享资源的个数。

P 操作和 V 操作都是原子操作。P 操作执行 S = S - 1，若 S < 0 则进程进入等待队列；V 操作执行 S = S + 1，若 S ≤ 0 则从队列中唤醒一个进程。

以生产者消费者问题为例：生产者先执行 P(S0) 申请仓库的互斥使用权，再执行 P(S1) 判断仓库是否有空闲，把商品放入仓库后执行 V(S2) 使商品数量加 1，最后执行 V(S0) 释放互斥信号量。消费者同样先申请互斥使用权，再执行 P(S2) 判断是否有商品，取出后执行 V(S1) 增加空闲位置，最后释放互斥信号量。

可以这样记：P 操作是主动的、带判断性质的减 1；V 操作是因为某个操作产生结果的加 1。

五、进程调度

调度方式分为可剥夺和不可剥夺两种：可剥夺指高优先级进程到来时强行剥夺正在运行进程的 CPU；不可剥夺指高优先级进程必须等待当前进程自动释放 CPU。

三级调度：高级调度（长调度或作业调度，决定哪个作业可以调入系统）、中级调度（对换调度，决定哪个就绪进程可以调入内存）、低级调度（进程调度，决定内存中哪个就绪进程占用 CPU）。

调度算法：

  • 先来先服务 FCFS：先到达的进程优先分配 CPU，用于宏观调度
  • 时间片轮转：各进程轮流使用 CPU，时间片大小相同，公平，用于微观调度
  • 优先级调度：优先级大的先分配 CPU
  • 多级反馈调度：时间片轮转与优先级调度结合，设置多个就绪队列并赋予不同优先级和时间片长度，新进程先进队列 1，未执行完则转入下一级队列末尾

六、死锁

当一个进程在等待永远不可能发生的事件时就会产生死锁；若系统中多个进程处于死锁状态，则造成系统死锁。

死锁产生的四个必要条件：资源互斥、每个进程占有资源并等待其他资源、系统不能剥夺进程资源、进程资源图形成环路。

处理方式：

  • 死锁预防：限制并发进程对资源的请求，破坏四个条件之一
  • 死锁避免：一般采用银行家算法，提前计算出一条不会死锁的资源分配方案，能保证归还才分配资源
  • 死锁检测：允许死锁产生，定时运行检测程序，发现死锁后设法解除
  • 死锁解除：强制剥夺资源、撤销进程等

死锁资源计算：系统内有 n 个进程，每个进程都需要 R 个资源，则发生死锁的最大资源数为 n × (R - 1)，不发生死锁的最小资源数为 n × (R - 1) + 1。

七、线程

传统进程有两个属性：是拥有资源的独立单位，也是可独立调度和分配的基本单位。

引入线程后，线程是独立调度的最小单位，进程是拥有资源的最小单位。线程可以共享进程的公共数据、全局变量、代码和文件等资源，但不能共享线程独有的资源，如栈指针等标识数据。
