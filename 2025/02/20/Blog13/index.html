摘要：本文梳理上午考试计算机组成与结构的第一部分，包括机器数的四种编码、浮点数表示与运算、逻辑运算与溢出判断，以及奇偶校验、CRC、海明码三种校验码的计算方法。

一、机器数与编码

各种数值在计算机中的表示形式称为机器数，其特点是使用二进制计数制，数的符号用 0 和 1 表示，小数点位置是隐含的，不占存储位。

机器数分为无符号数和带符号数。无符号数没有符号位；带符号数最高位是符号位，正数为 0，负数为 1。

定点表示法分为纯小数和纯整数两种，小数点都不占存储位，而是靠约定：

  • 纯小数：小数点约定在机器数最高数值位之前
  • 纯整数：小数点约定在机器数最低数值位之后

机器数对应的实际数值称为真值。

四种编码方式

编码 规则 0 的表示
原码 最高位为符号位，其余位是数值的绝对值的二进制 +0（00000000）、-0（10000000）
反码 正数与原码相同；负数除符号位外按位取反 +0（00000000）、-0（11111111）
补码 正数与原码相同；负数取反后末位加 1，有进位则进位 只有一种：00000000
移码 在补码基础上把符号位取反，用作浮点数的阶码 只有一种

需要注意的是，原码的最高位只表示正负号、不参与计数；而反码、补码、移码的最高位虽然也表示正负号，但参与计数，这也是它们表示范围不同的原因。

各种码制的表示范围

设机器字长为 n：

码制 定点整数 定点小数
原码 -(2^(n-1)-1) ~ +(2^(n-1)-1) -(1-2^-(n-1)) ~ +(1-2^-(n-1))
反码 -(2^(n-1)-1) ~ +(2^(n-1)-1) -(1-2^-(n-1)) ~ +(1-2^-(n-1))
补码 -2^(n-1) ~ +(2^(n-1)-1) -1 ~ +(1-2^-(n-1))
移码 -2^(n-1) ~ +(2^(n-1)-1) -1 ~ +(1-2^-(n-1))

二、浮点数

浮点数的表示方法是 N = F × 2^E，其中 E 称为阶码，F 称为尾数，相当于十进制的科学计数法。例如 101.011 = 0.101011 × 2^3。

浮点数的格式为「阶符、阶码、数符、尾数」。其中阶码是带符号的纯整数，尾数是带符号的纯小数。浮点数能表示的数值范围由阶码决定，数值精度由尾数决定。

尾数采用规格化表示，即带符号尾数的补码必须是 1.0xxxx（负数）或者 0.1xxxx（正数）。

浮点数的运算分三步：

  1. 对阶：使两个数的阶码相同，小阶向大阶看齐，较小阶码增加几位，尾数就右移几位
  2. 尾数计算：相加，若是减法则加负数
  3. 结果规格化：转换为 1.0xxxx 或 0.1xxxx 的形式

三、算术运算、逻辑运算与溢出判断

基本逻辑运算包括：

  • 逻辑与：有一个为 0 结果就为 0，两个都为 1 才为 1
  • 逻辑或：有一个为 1 结果就为 1，两个都为 0 才为 0
  • 异或：相同为 0，不同为 1
  • 逻辑非：0 的非是 1，1 的非是 0
  • 逻辑左移：整体左移 n 位，高位溢出舍去，低位补 0
  • 逻辑右移：整体右移 n 位，低位溢出舍去，高位补 0

算术左移和算术右移相当于乘以 2 或者除以 2。涉及加减乘除的属于算术运算，要和逻辑运算区分开。

短路计算：通过逻辑运算符左边表达式的值就能推算出整个表达式的值，不再继续执行右边的表达式。

溢出判断：若采用双符号位（00 表示正号、11 表示负号），两个符号相同的数相加时，如果结果的两位符号位经异或运算得 1，则可断定产生了溢出。正数和负数相加不会溢出，只有同号相加才可能溢出，溢出后符号位会变成 01 或者 10，这两种情况的两个符号位必然一个为 0、一个为 1。

四、校验码

码距：两个编码之间从 A 码转换为 B 码所需要改变的位数。单个编码 A：00 的码距为 1，A：00 与 B：11 之间的码距为 2。一般来说，码距越大越有利于检错和纠错。

奇偶校验码

在编码中增加 1 位校验位，使编码中 1 的个数为奇数（奇校验）或偶数（偶校验），码距变为 2。

接收方收到编码后计算其中 1 的个数：奇校验时若为奇数个则无误，为偶数个则有误。奇偶校验只能检测出奇数位错误，且无法纠错。

循环冗余校验码 CRC

CRC 只能检错，不能纠错。其原理是找出一个能整除多项式的编码：先把原始报文除以生成多项式，将余数作为校验位追加到原始报文之后发送。

使用 CRC 需要先约定生成多项式 G(x)，其最高位和最低位必须是 1。

例题：原始信息串为 10110，生成多项式 G(x) = x^4 + x + 1，求 CRC 校验码。

  1. 生成多项式阶为 4，在原始信息后添 4 个 0，得到被除数 101100000
  2. 由多项式得到除数：幂指数 0、1、4 存在，2、3 不存在，得到 10011
  3. 用模 2 除法（不进位不借位）计算，余数为 1111
  4. 将余数追加到原始信息之后，发送的数据为 101101111
  5. 接收方用同一个 G(x) 整除收到的数据，余数为 0 表示无错，否则要求重传

注意余数位数不足 r 时，要在左边补 0。收发双方必须使用相同的生成多项式。

海明校验码

海明码本质上也是奇偶校验，只是用多个校验位分别校验不同的数据位组合。

校验位个数 k 与数据位个数 n 的关系为 n + k ≤ 2^k - 1，考试时依次代入 k = 1、2、3……就能快速求出最小的满足条件的 k。

例题：求信息 1011 的海明码。

  1. 从最低位开始编号，校验位位于 1、2、4、8…… 位上，其余位放数据位。1011 共 4 位数据，由 n + k ≤ 2^k - 1 得 k = 3，即第 1、2、4 位为校验位 r0、r1、r2，第 3、5、6、7 位为数据位
  2. 把每个数据位的编号拆成二进制：7 = 4 + 2 + 1，6 = 4 + 2，5 = 4 + 1，3 = 2 + 1，说明第 7 位数据由 r2、r1、r0 共同校验，依此类推
  3. 每个校验位等于它负责的数据位的异或，结果要发送的海明码为 1010101
  4. 接收方把每位校验位与其负责的位数分别异或。偶校验时结果应全为 0，若不全为 0，把校验结果按 r2r1r0 排列成二进制，其数值就是出错位的编号，把该位取反即可纠错
