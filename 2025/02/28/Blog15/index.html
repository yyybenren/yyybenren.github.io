摘要：本文梳理上午考试计算机组成与结构的第三部分，包括存储系统层次、局部性原理、Cache 地址映射与置换算法、磁盘与 RAID、总线分类，以及串联并联系统的可靠性计算。

一、存储系统

存储层次与分类

计算机存储结构自快到慢依次为：CPU 寄存器、Cache、内存（主存）、外存（硬盘、光盘、U 盘等）。

采用分级存储体系的主要目的是解决存储容量、成本和速度之间的矛盾。两级存储映像为：Cache—主存、主存—辅存（虚拟存储体系）。

存储器的分类方式：

  • 按所处位置：内存、外存
  • 按构成材料：磁存储器（磁带）、半导体存储器、光存储器（光盘）
  • 按工作方式：可读可写存储器 RAM、只读存储器 ROM（PROM 可写入一次，EPROM 和 EEPROM 可多次改写）
  • 按访问方式：按地址访问、按内容访问（相联存储器）
  • 按寻址方式：随机存储器（访问任意单元时间相同）、顺序存储器（如磁带）、直接存储器（如磁盘，磁道寻址是随机的，磁道内是顺序的）

局部性原理

CPU 运行时访问的数据趋向于集中在较小的局部地址空间内。

  • 时间局部性：一个数据项正在被访问，则近期很可能被再次访问，例如循环语句
  • 空间局部性：最近将要访问的数据地址与当前访问的地址很可能相近，例如顺序访问数组
  • 工作集：进程运行时被频繁访问的页面集合

高速缓存 Cache

Cache 存储当前最活跃的程序和数据，直接与 CPU 交互，位于 CPU 和主存之间，容量小、速度是内存的 5～10 倍，由半导体材料构成，内容是主存的副本拷贝，对程序员是透明的。

Cache 由控制部分和存储器组成：存储器存数据，控制部分判断 CPU 要访问的数据是否在 Cache 中。

地址映射方法

映射方式 特点
直接映像 主存块与 Cache 块对应关系固定，块号相同才能命中，变换简单但不灵活，容易浪费资源
全相联映像 主存任意块可映射到 Cache 任意块，变换复杂、速度较慢，但最不容易发生块冲突
组相联映像 组间采用直接映像、组内全相联，是前两种方式的结合

置换算法

  • 随机算法：不考虑使用情况，随机选择一块替换
  • 先进先出 FIFO：淘汰最先进入 Cache 的块，实现简单但可能替换掉经常使用的程序块
  • 近期最少使用 LRU：淘汰近期最少使用的块，相对合理，但需要为每块设置「年龄计数器」，开销较大
  • 最不经常使用 LFU：淘汰引用计数最小的页，同时统计累计访问次数，实现复杂度和计数器规模都比 LRU 大

命中率与平均访问时间：设访问一次 Cache 的时间为 1ns，访问一次内存的时间为 1000ns，若命中率为 90%，则 CPU 读取一次的平均时间为 90% × 1 + 10% × 1000 = 100.9ns。

主存编址计算

  • 内存单元个数 = 内存尾地址 - 内存首地址 + 1
  • 内存容量 = 内存单元个数 × 每个内存单元容量（按字节编址时为 1 字节，即 8bit）
  • 把十六进制容量化为 2 的幂指数形式后再相除，不要直接硬算
  • 单位换算：1B = 8bit，1K = 1024，1M = 1024K

磁盘与 RAID

磁盘有正反两个盘面，每个盘面有多个同心圆（磁道），每个磁道划分成多个扇区，数据存放在扇区中。

存取时间 = 寻道时间 + 等待时间（平均定位时间 + 转动延迟）。其中寻道时间是磁头移动到指定磁道的时间，等待时间是等待读写扇区转到磁头下方的时间，寻道时间最长，是调度的重点。

磁盘调度算法：

  • 先来先服务 FCFS：按请求访问磁盘的先后顺序调度
  • 最短寻道时间优先 SSTF：优先调度与当前磁道最近的请求，可能产生「饥饿」现象
  • 扫描算法 SCAN：又称电梯算法，磁头双向移动，只访问与移动方向一致的请求
  • 单向扫描算法 CSCAN：只做单向移动

RAID 磁盘冗余阵列：

级别 特点
RAID0 没有冗余和错误修复能力
RAID1 成对独立磁盘互为备份，可提高读取性能，磁盘利用率 50%
RAID2 数据条块化分布，使用海明码校验
RAID3 使用奇偶校验，用单块磁盘存储校验信息
RAID5 所有磁盘交叉存储数据及奇偶校验信息，校验信息总量为一个磁盘容量
RAID0+1 两个 RAID0 组合，一个磁盘损坏会导致当前 RAID0 无法工作
RAID1+0 两个 RAID1 组合，不允许同一组中两块磁盘同时损坏，利用率 50%

二、总线

广义上任何连接两个以上电子元器件的导线都可以称为总线，通常分为三类：

  • 内部总线：芯片级别的总线，用于芯片与处理器之间通信
  • 系统总线：板级总线，用于计算机内各部分之间的连接，分为数据总线（CPU 与 RAM 之间传送数据，表示并行传输位数）、地址总线（指定存储数据的地址，表示可管理内存空间大小）、控制总线（把控制信号送到周边设备，如 ISA、EISA、PCI）
  • 外部总线：设备一级的总线，如 RS232（串行）、SCSI（并行）、USB（通用串行总线，即插即用、支持热插拔）

并行总线含多条双向数据线，适合近距离高速传输；串行总线只有一条双向数据线，适合长距离传输但速率较低。

三、系统可靠性

可靠性指标：

  • 平均无故障时间 MTTF = 1 / 失效率
  • 平均故障修复时间 MTTR = 1 / 修复率
  • 平均故障间隔时间 MTBF = MTTF + MTTR
  • 系统可用性 = MTTF / (MTTF + MTTR) × 100%

设每个设备的可靠性为 R1、R2……Rn：

  • 串联系统：任一设备不可靠则整个系统崩溃，R = R1 × R2 × …… × Rn
  • 并联系统：所有设备都不可靠时系统才崩溃，R = 1 - (1 - R1)(1 - R2)……(1 - Rn)

混合系统的做法是先划分出串联和并联结构再逐层计算。例如 R1、R2 并联后与 R3 串联，再与 R4 串联的可靠性为 (1 - (1 - R1)(1 - R2)) × R3 × R4。
