软考系统分析师-基础知识-系统规划与可行性研究

摘要：本文梳理上午考试系统规划部分，包括系统规划六个步骤、项目机会选择、可行性分析的四类与八个步骤，以及成本分类、收益分类和盈亏平衡点、净现值、投资回收期等计算。

一、系统规划步骤

  1. 对现有系统进行初步调查：根据企业战略和发展目标，从类似企业和本企业内部收集各种信息，站在管理层的高度观察企业现状，分析现有系统的运行状况
  2. 分析和确定系统目标：系统目标应包括服务的质量和范围、政策、组织和人员等，不仅包括信息系统的目标，还要反映整个企业的目标
  3. 分析子系统的组成和基本功能：自顶向下对系统进行划分，并详细说明各个子系统应实现的功能
  4. 拟定系统的实施方案：可以对子系统的优先级进行设定，以便确定开发顺序
  5. 进行系统的可行性研究，编写可行性研究报告，召开可行性论证会
  6. 制订系统建设方案：对可行性研究报告中提出的各项技术指标进行分析比较，落实各项假设的前提条件，并根据方案及实施计划编写系统设计任务书。系统设计任务书经上级主管部门批准后，正式作为系统建设的依据

项目机会选择的顺序：立项目标和动机 → 立项价值判断 → 项目选择和确定 → 初步调查 → 可行性分析。

二、可行性分析

可行性是指在企业当前条件下是否有必要建设新系统，以及建设新系统的工作是否具备必要条件，即包括必要性和可能性。

可行性分析的步骤：

  1. 复查系统目标和规模
  2. 分析现有系统
  3. 导出新系统的高层逻辑模型
  4. 用户复核
  5. 提出并评价解决方案
  6. 确定最终推荐的解决方案
  7. 草拟开发计划
  8. 编制和提交可行性分析报告

可行性研究通常从四个方面分析，其中经济可行性通常被认为是项目的底线：

类型 分析内容
经济可行性 也称投资收益分析或成本效益分析，评估项目的建设成本、运行成本和可能的经济收益。收益可分为直接与间接、有形与无形、一次性与非一次性、可定量与不可定量
技术可行性 也称技术风险分析，研究对象是信息系统需要实现的功能和性能以及技术能力约束，主要考虑技术（现有技术能力是否足以支持系统目标）、资源（掌握技术的员工、技术积累、构件库、软硬件条件）、目标三方面。技术可行性绝不仅仅是论证技术手段上是否可实现，还包含当前资源条件下的技术可行性
法律可行性 也称社会可行性，从政策、法律、道德、制度等社会因素论证信息系统建设的现实性
用户使用可行性 也称执行可行性，从用户角度评估系统可行性，包括企业的行政管理和工作制度、使用人员的素质和培训要求，可细分为管理可行性和运行可行性

用户使用可行性的两个细分：

  • 管理可行性：从企业管理上分析系统建设可行性。主管领导不支持的项目一般会失败，中高层管理人员抵触情绪大就有必要先做思想工作；还要考虑管理方法是否科学、相应管理制度改革的时机是否成熟、规章制度是否齐全
  • 运行可行性：也称操作可行性，分析和测定信息系统在确定环境中能够有效工作并被用户方便使用的程度和能力，例如 ERP 建成后的数据采集与数据质量问题、工作人员 IT 技能不足等

需要注意：系统开发初期用户需求和候选方案尚未确定，成本不可能准确估算，此时的经济可行性只能大致估算成本与收益，判断建设是否值得。

三、成本效益分析

成本分类

成本类型 说明 例子
固定成本 总额在一定期间和一定业务量范围内不随业务量变动而保持固定不变 管理人员工资、办公费、固定资产折旧费、员工培训费
变动成本 总额随业务量变动而成正比例变动 直接材料费、产品包装费、外包费用、开发奖金
混合成本 混合了固定成本和变动成本的性质 水电费、电话费，通常有一个基数，超过基数后随业务量增大
直接成本 直接投入在项目上 项目组人员工资、材料费用
间接成本 分摊到项目上 水电费、员工培训费
沉没成本 已经投入项目中、无法挽回的成本 不需要再考虑

收益分类：有形收益是能够直接带来营业额和利润增长的收益；无形收益不一定能导致营业额和利润增长，但能增加公司名气、信誉等。

常用计算

盈亏平衡点

利润 = 销售额 - 成本 = 销售额 -（固定成本 + 可变成本）。当利润为 0 时即为盈亏平衡点：

盈亏平衡点销售额 = 总固定成本 + 总可变成本 = 总固定成本 + 可变成本占销售额的比例 × 盈亏平衡点销售额

注意：可变成本与销售收入（销量）成正比，固定成本一直不变。

净现值 NPV

静态收益计算不考虑金钱的时间价值，只看项目周期内投入与产出的绝对数字；动态收益计算要考虑金钱的时间价值。设每年折现率为 i，原价值为 F 的东西在 n 年后的价值为 P = F / (1 + i)^n。

净现值 NPV 是考虑金钱的时间价值计算出的净利润，把项目周期内每年的（收入 CI - 支出 CO）按折现率折现后累加即得。NPV 有助于公司判断项目是否盈利。

净现值率 NPVR 是项目净现值与原始投资总额的比率，有助于公司选择投入小、产出高的项目。

投资回收期

  • 静态投资回收期 = 累计净现金流量开始出现正值的年份数 - 1 +（之前累计总成本 - 之前累计总收益）/（当年收益 - 当年成本）
  • 动态投资回收期 = 累计折现值开始出现正值的年份数 - 1 +（之前总成本折现值 - 之前总收益折现值）/（当年收益折现值 - 当年成本折现值）
  • 投资回收率 = 1 / 投资回收期 × 100%
  • 投资收益率 = 投资收益 / 投资成本 × 100%
