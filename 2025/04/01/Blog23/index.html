软考系统分析师-基础知识-IP 地址、IPv6 与网络规划设计

摘要：本文梳理上午考试计算机网络的第二部分，包括 IP 地址分类与主机数计算、子网划分与超网聚合、无分类编址、特殊含义地址、IPv6 的表示方法与过渡技术，以及网络规划设计的拓扑结构与五个阶段。

一、IP 地址分类

IP 地址由四段组成，每段 8 位，共 32 位二进制数。逻辑上分为网络号和主机号，依据网络号位数的不同分为几类：

类别 地址范围 网络号位数
A 类 0.0.0.0 ～ 127.255.255.255 8 位
B 类 128.0.0.0 ～ 191.255.255.255 16 位
C 类 192.0.0.0 ～ 223.255.255.255 24 位
D 类 224.0.0.0 ～ 239.255.255.255 组播地址
E 类 240.0.0.0 ～ 255.255.255.255 保留

A 类地址网络号占 8 位，主机号占 24 位，能分配的主机个数为 2^24 - 2 个；同理 B 类主机号占 16 位，C 类主机号占 8 位。减 2 是因为主机号全 0 和全 1 是特殊地址，不能分配。

二、子网划分与超网聚合

按 A、B、C 三类划分时，各类网络的主机数相差太大，不利于分配，因此采用子网划分：把主机号拿出几位作为子网号，IP 地址组成为「网络号 + 子网号 + 主机号」，这样就能根据实际主机数量划分出合适的方案，避免浪费。

子网掩码：网络号和子网号的位都为 1，主机号的位都为 0。

需要注意的规则：

  • 子网号可以为全 0 和全 1，主机号不能为全 0 或全 1，所以主机数要减 2，而子网数不用减
  • 判断两个 IP 地址是否在同一网段，只需比较网络号是否相同

超网聚合是划分子网的逆过程：把网络号取出几位作为主机号，这样网络内的主机数量变多，形成一个更大的网络。

三、无分类编址

无分类编址不按 A、B、C 类规则划分，而是自动规定网络号，格式为「IP 地址/网络号」，例如 128.168.0.11/20 表示该 IP 的网络号占 20 位，主机号占 32 - 20 = 12 位，同样可以继续划分子网。斜杠后面的数字是网络号位数，用 32 减去它就是主机号位数。

四、特殊含义的 IP 地址

地址 含义
127 网段 回播地址
网络号全 0 当前子网中的主机
全 1 地址 本地子网的广播
主机号全 1 特定子网的广播
10.0.0.0/8 私有地址，10.0.0.1 ～ 10.255.255.254
172.16.0.0/12 私有地址，172.16.0.1 ～ 172.31.255.254
192.168.0.0/16 私有地址，192.168.0.1 ～ 192.168.255.254
169.254.0.0 保留地址，用于 DHCP 失效（Windows）
0.0.0.0 保留地址，用于 DHCP 失效（Linux）

五、IPv6

IPv6 是为解决 IPv4 地址不够用而提出的，主要特性：

  • 地址长度为 128 位，地址空间增大了 2^96 倍
  • 采用一系列固定格式的扩展头部取代 IPv4 中可变长度的选项字段，路由器可以简单跳过选项不做处理，加快报文处理速度
  • 简化报文头部格式，加快转发，提高吞吐量
  • 提高安全性，身份认证和隐私权是关键特性
  • 支持更多服务类型，允许协议继续演变以适应未来技术

地址表示与压缩规则

IPv6 采用十六进制表示，每 4 个十六进制数为一组，组间用冒号分隔，共 8 组。

压缩规则：

  • 前面的 0 可以省略，后面的 0 不能省
  • 连续的多个 0 可以用冒号压缩，但零压缩在整个地址中只能出现一次
  • 支持 IPv4 兼容写法

例如下面几种写法是等价的：

2001:0DB8:0000:0000:0000:0000:1428:57ab

2001:0DB8:0:0:0:0:1428:57ab

2001:0DB8:1428:57ab

IPv6 的地址类型

IPv6 分为多播、任播和单播三类（IPv4 则分为组播、广播和单播）：

  • 多播：前缀为 11111111（即 0xFF），代表一组地址，发送多播数据时组内所有主机都会收到
  • 任播：子网前缀固定、其余位置为 0 的地址，是 IPv6 独有的类型，发送数据时组内只有一个主机收到（离发送端口最近的路由端口所在主机），可作为目标地址但不能做源地址
  • 单播：分为可聚合全球单播地址（前缀 001，类似 IPv4 公有地址）、链路本地单播地址（前缀 1111111010，相当于自动专用 IP）、站点本地单播地址（前缀 1111111011，即 IPv6 的私网地址）、特殊单播地址（不确定地址 0:0:0:0:0:0:0:0 不能作为目的地址，回环地址 0:0:0:0:0:0:0:1 用于回环测试）

IPv4 到 IPv6 的过渡技术

  1. 双协议栈：主机同时运行 IPv4 和 IPv6 两套协议栈，同时支持两套协议
  2. 隧道技术：在 IPv4 网络之上建立一条能传输 IPv6 数据报的隧道，把 IPv6 数据报当作 IPv4 数据报的数据部分封装
  3. 翻译技术：用专门的翻译设备（转换网关）在纯 IPv4 和纯 IPv6 网络之间转换 IP 报头地址，同时做语义翻译

六、网络规划与设计

网络分类与拓扑结构

网络分类 缩写 分布距离 传输速率范围
局域网 LAN 10m～1000m 左右（房间、楼寓、校园） 4Mbps～1Gbps
城域网 MAN 10km（城市） 50Kbps～100Mbps
广域网 WAN 100km 以上（国家或全球） 9.6Kbps～45Mbps

常见拓扑结构：总线型（利用率低、干扰大、价格低）、星型（交换机组网、中央单元负荷大）、环型（流动方向固定、效率低、扩充难）、树型（总线型的扩充、分级结构）、分布式（任意节点连接、管理难成本高）。

办公室局域网一般是星型结构，中间节点是交换机；由路由器连接起来的小型网络同样是星型结构。这类结构的风险是中央节点一旦损坏，整个网络就瘫痪。

网络设计流程

  1. 需求分析：开发过程中最关键的阶段，通过与经理人员、网络管理员等不同用户交流收集需求，输出需求说明书（需求规范）
  2. 通信规范分析：如果是对现有网络升级改造，必须分析现有网络，目的是描述资源分布以便尽量保护已有投资，输出正式的通信规范说明文档
  3. 逻辑网络设计：根据需求规范和通信规范选择合适的网络逻辑结构，并进行资源分配规划、安全规划等，输出逻辑设计文档
  4. 物理网络设计：逻辑设计的具体实现，确定设备的物理分布、运行环境、软硬件、连接设备、布线和服务部署方案
  5. 安装和维护：实施环境准备、设备安装调试；网络投入运行后还要进行故障监测与恢复、网络升级和性能优化
