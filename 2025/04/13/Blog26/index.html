摘要：本文梳理上午考试系统安全的第二部分，包括各层安全协议、SSL/SET/Kerberos/IPSec/PGP 的原理，网络级与应用级防火墙、DMZ 屏蔽子网，入侵检测系统的四个模块，无线网络安全以及计算机病毒与木马。

一、各层安全协议

各层保证传输安全的手段不同，物理层靠物理手段，其余各层靠协议：

层次 安全手段与协议
物理层 隔离、屏蔽
数据链路层 链路加密、PPTP、L2TP
网络层 IPSec
传输层 防火墙
会话层 TLS、SET
表示层 SSL、HTTPS
应用层 PGP

SSL

SSL 协议常用于网银交易，提供三方面服务：用户和服务器的合法性验证、加密数据以隐藏被传输的数据、保护数据的完整性。

实现过程为：接通阶段 → 密码交换阶段（客户端和服务器交换双方认可的密码）→ 会谈密码阶段（产生彼此交谈的会谈密码）→ 检验阶段 → 客户认证阶段 → 结束阶段。

SSL 被设计为加强 Web 安全传输（HTTP/HTTPS，还有 SMTP/NNTP 等）的协议；SSH 则被设计为加强 Telnet/FTP 安全的传输协议。

SET

SET 是安全电子交易协议，主要应用于 B2C 模式的电子商务中保障支付信息的安全性。协议本身比较复杂、设计严格、安全性高，能保证信息传输的机密性、真实性、完整性和不可否认性。SET 是 PKI 框架下的一个典型实现。

Kerberos

Kerberos 是一种网络身份认证协议，基础是基于信任第三方，提供了在开放型网络中进行身份认证的方法，认证实体可以是用户也可以是用户服务。这种认证不依赖宿主机的操作系统或 IP 地址，不需要保证网络上所有计算机的物理安全性，并假定数据包在传输中可被随机窃取和篡改。

IPSec

IPSec 是 IETF 为保证在 Internet 上传送数据的保密性而制定的框架协议，应用在网络层，保护和认证 IP 数据包。它是开放的框架式协议，各算法之间相互独立，提供了信息的机密性、数据的完整性、用户的验证和防重放保护，集隧道技术、加密技术、认证技术、密钥管理技术于一体，支持隧道模式和传输模式。

IPSec 的功能组件：

  • 认证头 AH：用于数据完整性认证和数据源认证
  • 封装安全负荷 ESP：提供数据保密性和数据完整性认证，并包含防止重放攻击的顺序号
  • Internet 密钥交换协议 IKE：生成和分发 ESP、AH 中使用的密钥，也对远程系统进行初始认证

安全关联 SA 是 IPSec 的基础，是两个应用 IPSec 的系统（主机、路由器）之间的单向逻辑连接，是安全策略的具体化和实例化。一个 SA 由三元组唯一标识：安全参数索引 SPI、一个 IP 目的地址、一个安全协议（AH 或 ESP）标识符。

PGP

PGP 是安全电子邮件协议，提供两种服务：数据加密和数字签名。数据加密可用于本地文件，也可用于网络上传输的电子邮件；数字签名用于数据源身份认证和报文完整性验证。PGP 使用 RSA 公钥证书进行身份认证，使用 IDEA（128 位密钥）加密数据，使用 MD5 验证数据完整性。

发送方 A 持有三个密钥：A 的私钥、B 的公钥、A 生成的一次性对称密钥；接收方 B 持有两个密钥：B 的私钥、A 的公钥。

发送过程：A 用 SHA 对明文生成信息摘要，用 A 的私钥对摘要做数字签名，把摘要和明文都用一次性对称密钥加密，再用 B 的公钥加密这个对称密钥，最后整体发送。

接收过程：B 先用自己的私钥解密取出一次性对称密钥，用它解密密文得到摘要和明文，再用 A 的公钥核实数字签名得到摘要，同时对明文用 SHA 重新生成摘要并与收到的摘要比对，一致则安全。

二、防火墙

防火墙是在内部网络和外部因特网之间增加的一道安全防护措施，分为网络级防火墙和应用级防火墙。

网络级防火墙层次低但效率高，使用包过滤和状态检测手段，一般只检验网络包的外在属性（起始地址、状态）是否异常，异常则过滤掉，不与内网通信，因此对应用和用户是透明的。问题是遇到伪装的危险数据包就无法过滤，此时需要应用级防火墙。

应用级防火墙层次高但效率低，它会把网络包拆开检查里面的数据是否有问题，消耗大量时间、效率低下，但安全强度高。

常见结构有屏蔽路由器、双穴主机、屏蔽主机、屏蔽子网等。其中屏蔽子网是在内网和外网之间增加一个屏蔽子网，即 DMZ（非军事区），内外网通信必须多经过一道防火墙。DMZ 中一般存放邮件服务器、Web 服务器等需要内外网数据交互的服务器，可以屏蔽来自内部的攻击，但完全来自系统内部服务器的攻击仍无法屏蔽。

三、入侵检测系统

美国国防部高级研究计划局提出的公共入侵检测框架 CIDF 由四个模块组成：

  1. 事件产生器：负责数据采集，把收集到的原始数据转换为事件。入侵检测利用的信息一般来自四个方面——系统和网络的日志文件、目录和文件中不期望的改变、程序执行中不期望的行为、物理形式的入侵信息。要在网络中若干关键点（不同网段和不同主机）收集信息，通过多个采集点信息的比较判断是否存在可疑迹象
  2. 事件分析器：接收事件信息并分析判断是否为入侵行为或异常现象，分析方法有三种——模式匹配（与已知入侵数据库比较）、统计分析（为用户、文件、目录、设备建立正常使用特征，超出正常范围即认为可能入侵）、数据完整性分析（关注文件或系统对象属性是否被修改，多用于事后审计）
  3. 事件数据库：存放有关事件的各种中间结果和最终数据，可以是数据库也可以是文本文件
  4. 响应单元：根据报警信息做出反应，强烈的反应是断开连接、改变文件属性，简单的反应是发出系统提示引起操作人员注意

四、无线网络安全

WiFi 接入加密安全技术由低到高为 WEP < WPA < WPA2：

  • WEP：使用 RC4 协议加密，用 CRC-32 校验保证数据正确性
  • WPA：增加了安全认证技术，增大密钥和初始向量长度（128 比特密钥和 48 位初始向量用于 RC4 加密）；采用临时密钥完整性协议 TKIP，更频繁地变换密钥以降低安全风险；强化数据完整性保护，用报文完整性编码检测伪造数据包，并在报文认证码中包含帧计数器防止重放攻击
  • WPA2：在 WPA 基础上增加采用 AES 对称加密算法，比 RC4 更安全可靠

五、计算机病毒与木马

计算机病毒是编制或插入计算机程序中、破坏计算机功能或数据、影响计算机使用并能自我复制的一组计算机指令或程序代码。

病毒的特性：传染性、隐蔽性、潜伏性、破坏性、针对性、衍生性、寄生性、未知性。

病毒命名规则为「病毒前缀.病毒名.病毒后缀」。常见前缀：trojan（木马）、Hack（黑客程序）、worm（蠕虫病毒）、macro（宏病毒）、script（脚本病毒）、win32（针对 Windows 的病毒）。

病毒类型 特征 危害
文件型 感染 DOS 下的 COM、EXE 文件 随着 DOS 消失，危害越来越小
引导型 启动 DOS 系统时触发 随着 DOS 消失，危害越来越小
宏病毒 针对 Office，由 Office 的宏语言编写 只感染 Office 文档，以 Word 文档为主
VB 脚本病毒 通过 IE 浏览器激活 浏览网页时感染，清除较容易
蠕虫 有的通过电子邮件附件传播，有的利用操作系统漏洞攻击 破坏文件、造成数据丢失、使系统无法正常运行，是目前危害最大的病毒
木马 通常是病毒携带的附属程序 夺取计算机控制权
黑客程序 利用系统漏洞入侵的工具 常被计算机病毒携带用于破坏

木马是一种后门程序，常被黑客用作控制远程计算机的工具，隐藏在被控电脑上监控操作并盗取信息。

代表性病毒实例：蠕虫类有熊猫烧香、罗密欧与朱丽叶、恶鹰、尼姆达、冲击波、欢乐时光；木马类有 QQ 消息尾巴木马、特洛伊木马；宏病毒有美丽沙、台湾 1 号。其中 CIH 是史上唯一破坏硬件的病毒，红色代码是蠕虫病毒加木马。
